# 🚑 DomiMidol Medic Theme

A premium BetterDiscord & Vencord theme inspired by Emergency Medical Services.

Designed with a modern glassmorphism interface, transparent panels and a black & red color palette.

![Preview](assets/Preview.png)

---

## ✨ Features

- 🚑 EMS-inspired design
- ❤️ Red accent colors
- 🌫 Glassmorphism UI
- 🖼 Custom background support
- 👥 Transparent member list
- 💬 Modern chat layout
- 🎙 Voice panel redesign
- ⚡ Smooth animations
- 🔄 Automatic updates via GitHub

---

## 📦 Installation

1. Install BetterDiscord or Vencord.
2. Download `DomiMidolMedic.theme.css`.
3. Copy the file into your `themes` folder.
4. Enable the theme.
5. Enjoy.

---

## 🖼 Background

The default wallpaper is loaded from this repository.

You can replace:

assets/Background.png

with your own image while keeping the same filename.

---

## 🔄 Updating

BetterDiscord checks the `@updateUrl` automatically.

Simply replace the CSS file in this repository whenever a new version is released.
